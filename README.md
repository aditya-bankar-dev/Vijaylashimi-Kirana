# Grocery Store Management System
Stack: HTML/CSS/JS + Bootstrap 5 + Chart.js | Node.js + Express | MySQL 8

## Setup (Phase 1-2 done: database)
1. Install MySQL 8 and Node.js 18+
2. `mysql -u root -p < database/database.sql`
3. `mysql -u root -p < database/sample_data.sql`
4. `cp .env.example .env` and fill values; `npm install`

Sample logins (password `Admin@123`): admin@kirana.in, manager@kirana.in, cashier@kirana.in
